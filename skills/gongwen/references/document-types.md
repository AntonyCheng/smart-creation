# 文种选择与结构

## 15 种法定公文

| 文种 | 主要用途 | 起草校验重点 |
|---|---|---|
| 决议 | 会议讨论通过的重大决策事项 | 会议主体、通过日期、决议事项 |
| 决定 | 对重要事项作出决策部署或奖惩 | 决策依据、适用范围、执行要求 |
| 命令（令） | 公布规章、重大强制措施、任免奖惩 | 发布权限、令号、负责人专用签署、施行日期；不使用“签发人”标签 |
| 公报 | 公布重要决定或重大事项 | 发布主体、事实准确、公开范围 |
| 公告 | 向国内外宣布重要或法定事项 | 法定权限、公开对象、事项边界 |
| 通告 | 在一定范围公布应遵守事项 | 适用范围、行为要求、期限 |
| 意见 | 对重要问题提出见解和处理办法 | 指导原则、任务措施、责任分工 |
| 通知 | 发布、传达事项或批转文件 | 对象、事项、时间地点、要求 |
| 通报 | 表彰先进、批评错误、传达情况 | 事实依据、评价尺度、警示要求 |
| 报告 | 向上级汇报工作或回复询问 | 上行关系、资料提供时标注签发人、事实数据、不得夹带请示 |
| 请示 | 向上级请求指示或批准 | 上行文、资料提供时标注签发人、一文一事、明确请示事项、主送唯一 |
| 批复 | 答复下级请示 | 对应请示、明确结论、执行要求 |
| 议案 | 向审议机关提请审议事项 | 提案权限、案由、方案、审议请求及提出人专用署名，不使用“签发人”标签 |
| 函 | 不相隶属机关商洽、询答或审批 | 平行行文、信函专用版式、事项单一、语气得体 |
| 纪要 | 记载会议主要情况和议定事项 | 纪要专用版头、会议基本信息、议定事项、责任主体 |

## 常用事务文书

- 讲话稿：称谓、开场、主题层次、工作要求、结语；不默认使用红头。
- 工作总结：基本情况、主要做法、成效、问题、下一步安排；事实数据必须可追溯。
- 汇报材料：背景、进展、成效、问题、请求或下一步；区分“报告”法定文种。
- 工作方案：目标、原则、任务、步骤、责任、保障；时间节点和责任主体必须明确。
- 调研报告：问题、方法、证据、分析、建议；不得把推测写成事实。

## 决策规则

1. 用户明确指定文种且行文关系合理时采用该文种。
2. 用户指定文种与用途冲突时，先指出冲突并一次追问一个问题。
3. 无法判断时先确认受文对象与期望动作，再确定文种。
4. 法定公文采用国家格式；事务文书采用清洁、正式、可编辑的机关文稿版式。
5. 通知、决定、通报、批复等非上行文不标注签发人；意见须先根据实际行文方向判断。
6. 主送机关不是仅由文种决定的固定有无项。先判断是否存在需要办理或知晓的受文机关：有明确主送对象时编排，面向社会公开、普发或文种惯例无需主送时省略。决议可因发布和执行范围设置主送机关，也可在会议通过并公开发布的场景省略；不得断言“决议必须有主送机关”。
7. 标题下会议通过信息只在资料明确且该信息确有必要时编排。决议常见但不是所有决议一律强制；决定通常不标注，但用户提供合法通过信息且需要表现时按资料处理。
8. 是否加盖印章取决于发文形式、发文机关标志、发布方式和用户明确要求，不得按“决议、决定、命令”等文种一刀切。命令（令）采用负责人专用签署结构，不得误写成普通机关落款，也不得凭空生成负责人签名章。
9. 版记是否出现取决于是否形成印制、分发的正式版式以及是否有抄送机关、印发机关和印发日期等资料，不得按文种绝对判定“必须有”或“禁止有”。命令、公告、通告等在具体印发场景中也可能出现版记；缺少资料时不得虚构。
